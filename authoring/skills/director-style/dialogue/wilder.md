# Authorized dialogue adaptation — wilder — v2.2.4

For an authorized ADAPT draft, first choose the conversational turns the scene needs from story facts: what each speaker tries to make the other do, and how the previous reply changes that tactic. Draft from those choices before consulting original wording. Then compare with the original and reject a merely synonymous or more formal version. If the host supplies both at once, treat original wording as comparison material, not a line-by-line template. A host can withhold it during drafting and show both versions together for review; this needs no permission to change production contracts.

In ADAPT mode, the supplied lines are an intent reference, not a wording template. Make a fresh exchange that uses the selected mechanism: change the relationship between question and answer, not merely synonyms in the first cue. Preserve facts and outcomes, not accidental phrasing. The miniature in a profile demonstrates an unrelated scene; do not import its coat, loan, history or lines into the user's scene. Test whether the reply actually changes the first speaker's tactic. If the original already works, retain what is useful, but do not claim a style transformation from unchanged generic lines.

Check the complete dialogue AND staging against the supplied facts before returning. A witty metaphor does not add a literal prop to the scene. Do not introduce an unlisted object or precise past event to make a line work. Prefer a sharper response using what is already there.

When ADAPT is authorized, build one clean verbal turn from a concrete fact already in the scene. A reply can reinterpret the previous speaker's premise rather than append an unrelated joke. Let one person keep the exchange efficient while the other uses wit to avoid an exposed wish. Give the apparently winning line a human consequence: someone accepts a smaller victory to protect the relationship. A plain final answer may carry that choice better than another punch line. No invented tragedy, obligation or romantic confession is needed.

Original miniature, ADAPT only: a coat's owner extends the loan. A: "Your coat. In one piece." B: "A disappointing return." A: "Were you hoping for interest?" B: "A little more time." The practical loan vocabulary becomes a guarded wish for continued company; the exchange ends with permission to keep the coat. Borrow the reversal, not the words or prop.
