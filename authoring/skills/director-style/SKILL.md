# A scene should work with the director's name removed

Read `references/shared.md` and exactly one selected `profiles/*.md`. The host's task, schema and user facts take precedence. These are authored technique interpretations, not official filmmaker skills or guaranteed reproductions. Collaborating writers and actors contribute to the films; do not attribute every screenplay trait to its director.

Planning hosts that need one compact packet may load the matching `injection/*.md` instead. Do not load both representations. Description refinement uses shared rules plus the selected profile; it does not become a new script/asset-selection task. Style is not injected into vision, asset selection or the H3 writer.

Dialogue is LOCKED unless the user explicitly authorizes ADAPT. In LOCKED mode preserve speaker, language, words and order; style the delivery, listening and coverage. In ADAPT mode propose original dialogue as a separate script draft for review, preserving the supplied event outcomes. A skill never grants permission to bypass the host's exact-dialogue validation. The current Shot Workspace plan/refine routes retain source words: an adapted script must become the supplied source before those routes run.

Select `baseline`, `anderson`, `wilder`, `coen`, `fincher` or `ozu`. Import this whole folder in **Director Storyboard (optional) → Import skill folder**. Source/provenance and limits are in SOURCES.md; they are not runtime dependencies. No network requests, scripts, assets or video jobs are part of skill execution.

For an explicitly authorized dialogue-drafting task only, additionally read the selected file in `dialogue/`. Normal planning/refinement does not read that folder. It contains original miniature examples and adaptation guidance; keeping it separate avoids asking a locked-dialogue task to compose a new screenplay.
