# Changelog

## 0.1.0

- Initial independent node package: shared assets, multiple drafts and one-active-shot generation.
- OpenAI-compatible text/vision authoring, connection tests and separate operation timings.
- Ordered image references, current-prompt validation and explicit workflow/media interfaces.
- Opt-in LLM unloading and provider-neutral new-workspace defaults.
- Native H3 timing/audio-window helpers.
- Three sample integrations, a native first-clip bootstrap helper, pinned upstream originals and public fixture inputs.
- Four successful GPU reruns with public inputs, bundled output clips and verification hashes.

Experimental release. Automatic predecessor selection, sequence orchestration and universal latent conversion are not implemented.
